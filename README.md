# samuel-portfolio

nNo ar: https://samuelsilvacode.github.io/samuel-portfolio/
Portfólio com versões de demonstração de dois sistemas que desenvolvi: um portal de vendas/CRM e uma central de RH. A empresa e os dados são fictícios.

- `/#/crm`: painel comercial, pipeline em kanban, ficha do cliente com linha do tempo, pedidos com exportação
- `/#/rh`: colaboradores, processo seletivo, treinamentos e PDI, pesquisa de clima, reserva de salas

Feito com React, TypeScript, Vite, Tailwind e Recharts.

```bash
npm install
npm run dev
```
